Privacy Policy

SchoolCore Backup rclone

Google account used

This integration uses a dedicated backup Google account controlled by the SchoolCore owner. That account is used solely to hold encrypted off-site SchoolCore backup data.

Permission requested

Access is requested with the drive.file scope. This grants the integration access only to files and folders it creates or manages. It cannot read, list or modify unrelated content in the account.

What is stored

  • Encrypted backup repository objects for SchoolCore.
  • Backup data is encrypted using Restic before upload, so stored objects are not readable as plaintext.
  • No Google account password is ever collected or stored.

How data is used

Stored data is used solely for backup, integrity checking, retention management and restore operations. Google user data is not sold and not shared for advertising or marketing.

Where credentials are kept

OAuth credentials are held securely on the owner's self-hosted server and are never exposed publicly.

Revoking access

The owner may revoke Google OAuth access at any time through their Google account security settings, after which the integration can no longer reach the backup data.
