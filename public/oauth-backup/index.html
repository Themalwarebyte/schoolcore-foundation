SchoolCore Backup rclone

Backup integration for the SchoolCore self-hosted platform

What this is

SchoolCore Backup rclone is an owner-operated backup utility for the SchoolCore self-hosted school management platform. It is operated privately by the SchoolCore owner and is not offered as a public consumer service.

How it works

  • It connects to a dedicated Google Drive account whose sole purpose is to store encrypted off-site SchoolCore backup data.
  • Google Drive access uses the drive.file OAuth scope, so the integration can only reach files and folders it creates and manages for the backup repository.
  • Backup data is encrypted by Restic before it is stored in Google Drive.
  • Google account passwords are never collected or stored by SchoolCore. Authorisation is performed through Google's OAuth flow.

Data handled

The integration stores only encrypted backup repository objects. It does not read, store or transmit any personal, student, staff or school data beyond what is already contained inside the encrypted backup archive.
